# Alpha 2 network reset: notice to testers

Draft for [#195](https://github.com/happenings-community/requests-and-offers/issues/195). Send it once the last alpha 2 DNA change has merged and the release date is fixed, then fill the two dates. Post it in the testers' channel and as a discussion on the repository; the release note carries the short form from `CHANGELOG.md`.

---

**Requests and Offers alpha 2: a fresh network on RELEASE_DATE**

Alpha 2 moves Requests and Offers to Holochain 0.7 and changes the app's DNA. A new DNA means a new network, so on RELEASE_DATE alpha 2 starts empty.

What does not carry over: profiles, organisations, requests, offers, service types, exchanges, messages and any admin decision (accepted members, roles, suspensions). Everyone signs up again, and organisations are created again.

What stays: nothing is deleted from your computer. Alpha 1 keeps its data where it is, and alpha 2 starts in its own folder beside it.

Why: the alpha networks are test networks until v0.6.0. We batch every DNA change into as few releases as we can, but until v0.6.0 a new release can still need a new network, and we say so before it happens.

Where your data goes from here: carrying data across a DNA change is planned work, the breaking-version migration in [#144](https://github.com/happenings-community/requests-and-offers/issues/144). Until it lands, treat alpha data as disposable: please do not put anything in it you would not want to type again.

What to do on RELEASE_DATE: install alpha 2, create your profile, and ask an admin to accept you again. If you were an admin or ran an organisation, PERSON_TO_CONTACT will help you set things up again.

Questions or feedback: the [Release feedback](https://github.com/happenings-community/requests-and-offers/discussions/categories/release-feedback) discussions.
